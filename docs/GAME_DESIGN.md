# Make Ten — 게임 초기 기획서

> 모바일 우선 숫자 퍼즐 게임. 드래그로 숫자를 묶어 10을 만들고, 점수로 스킬을 해금하며 반복 플레이하는 아케이드 퍼즐.

- 문서 버전: v0.1 (초기 구상)
- 작성일: 2026-08-08
- 상태: 컨셉 확정 전 — "열린 질문" 섹션의 결정이 필요함

---

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 장르 | 아케이드 숫자 퍼즐 (타임어택) |
| 플랫폼 | 모바일 우선 (iOS / Android), 세로 화면 고정 |
| 세션 길이 | 판당 2~3분 (짧고 반복적인 플레이) |
| 핵심 재미 | ① 빠른 눈–손 스캔의 몰입감 ② 스킬 해금으로 판이 점점 화려해지는 성장감 |
| 레퍼런스 | 사과게임(Fruit Box), Threes/2048류의 숫자 감각, 로그라이트식 메타 성장 |

**한 줄 컨셉**: "10을 만들면 사라진다" 라는 단순한 규칙 위에, 스킬트리로 **새로운 목표 숫자(13, 17…)와 배율**을 해금해 매 판이 조금씩 달라지는 타임어택 퍼즐.

---

## 2. 핵심 게임플레이 (Core Loop)

### 2.1 보드

- 격자 그리드에 **1~9 숫자 타일**이 랜덤 배치.
- 권장 그리드: 세로 모바일 기준 **7열 × 10행** (엄지 드래그 조작에 적당한 타일 크기 확보. 기기 화면비에 따라 6×9 ~ 8×12 사이에서 튜닝).
- 숫자 생성 분포는 균등분포에서 시작하되, "10을 만들 수 있는 조합이 항상 존재"하도록 데드락 검사 후 보정.

### 2.2 조작

- **드래그로 직사각형 영역 선택** (시작점 → 현재 터치 지점이 사각형의 대각선).
- 드래그 중 실시간으로:
  - 선택 영역 하이라이트
  - 영역 내 숫자 합계 표시 (손가락 근처 or 상단)
  - 합이 10이면 초록색 등으로 "성립" 피드백
- 손을 떼는 순간 판정:
  - **합계 = 10** → 영역 내 숫자 타일 제거 + 점수 획득
  - 그 외 → 선택 취소 (페널티 없음, 스피드가 생명이므로 실패 비용은 0)

### 2.3 타일 제거 후 처리 — ✅ 고정 보드(빈 공간 방식)로 확정

- 지운 자리는 **빈칸으로 남는다** (사과게임 방식). 리필/중력 없음.
- 한 판의 보드가 곧 퍼즐: 남은 숫자들 사이에서 조합을 짜내는 최적화 재미가 핵심.
- 고정 보드의 약점이었던 "판당 점수 상한 → 스킬 성장이 티가 안 남" 문제는 **리롤(2.4)** 이 해결한다. 리롤 횟수가 곧 점수 상한을 늘리는 자원이므로, 스킬트리로 리롤을 해금할수록 기록 갱신이 가능해진다.
- 빈칸을 사이에 둔 선택도 허용: 사각형 영역 안의 빈칸은 무시하고 남은 숫자들의 합만 판정한다 (보드가 비어갈수록 큰 사각형을 그리는 재미).

### 2.4 리롤 (Reroll) — 핵심 자원

- 버튼을 누르면 **남아있는 모든 숫자 타일이 새 랜덤 숫자로 교체**된다 (빈칸은 빈칸 유지).
- 기본 **판당 1회**. 스킬트리 해금으로 최대 횟수 증가.
- 사용 타이밍이 곧 전략: 조합이 마르기 전에 일찍 쓸지, 보드를 최대한 긁어낸 뒤 쓸지.
- 성립 가능한 조합이 하나도 없으면 리롤 버튼을 강조 연출로 안내 (리롤이 없으면 남은 시간 동안 관전 — 이를 피하려는 동기가 리롤 스킬 투자로 이어짐).

### 2.5 제한 시간

- 기본 **120초**. 스킬로 시작 시간/추가 시간 확보 가능.
- 종료 10초 전 경고 연출(타이머 붉어짐 + 심박 사운드).

## 3. 점수 시스템

| 요소 | 규칙 (초기값, 밸런싱 대상) |
|---|---|
| 기본 점수 | 합 10 성립 시 **+10점** |
| 타일 수 보너스 | 3개 이상 타일로 10을 만들면 타일당 +2점 (예: 4개 조합 = 10 + 8 = 18점). "큰 영역을 읽는" 실력에 보상 |
| 콤보 | 3초 이내 연속 제거 시 콤보 게이지 상승. 콤보 x2, x3… 배율 (스킬로 해금/강화) |
| 피버 | 콤보 게이지 최대 시 10초간 전 점수 2배 (후순위 확장) |

점수는 판이 끝나면 **코인(메타 재화)** 으로 환산되어 적립된다 (예: 100점 = 10코인). "점수 = 실력 지표", "코인 = 성장 재화"로 역할 분리.

## 4. 스킬트리 (메타 진행)

판에서 번 코인으로 영구 스킬을 해금. **4개 계열**로 구성해 취향에 따른 빌드 선택을 유도한다.

### 4.1 배점(Score) 계열 — "더 많이"

| 스킬 | 효과 | 비고 |
|---|---|---|
| 점수 강화 I~V | 기본 점수 +10% / 단계 | 저렴한 초반 성장 |
| 대물 사냥꾼 | 5타일 이상 조합 시 점수 2배 | 플레이 스타일 변화 |
| 콤보 마스터 I~III | 콤보 유지 시간 +1초 / 최대 배율 상승 | |

### 4.2 조합(Combination) 계열 — "새로운 규칙" ★차별화 포인트

10 외의 **특수 목표 숫자**를 해금. 특수 숫자는 일부러 만들기 어렵기 때문에 리스크–리워드가 생긴다.

| 스킬 | 효과 |
|---|---|
| **럭키 13** | 합 13으로 지우면 십자 방향 인접 타일까지 함께 폭발, 폭발 제거 타일당 +3점 |
| **타임 17** | 합 17로 지우면 제한 시간 +3초 |
| **더블 20** | 합 20으로 지우면 해당 조합 점수 3배 |
| **프라임 헌터** | 소수 합(7, 11, 13, 17, 19…)도 제거 가능, 단 점수는 합의 절반 (상위 해금, 판을 완전히 바꾸는 스킬) |

> 특수 숫자는 "10이 안 되는 실수"를 "의도된 플레이"로 바꿔준다는 점에서, 실패 경험 자체를 성장으로 회수하는 장치.

### 4.3 시간(Time) 계열 — "더 오래"

| 스킬 | 효과 |
|---|---|
| 시간 연장 I~III | 시작 시간 +10초 / 단계 |
| 모래시계 | 10 제거 성공 시마다 +0.3초 |
| 라스트 스퍼트 | 종료 전 마지막 15초간 점수 1.5배 |

### 4.4 유틸(Utility) 계열 — "더 편하게"

| 스킬 | 효과 |
|---|---|
| 리롤 충전 I~II | 판당 리롤 최대 횟수 +1 / 단계 (기본 1회 → 최대 3회). 유틸 계열의 중심 축 |
| 부분 리롤 | 리롤 사용 시 전체 대신 **드래그로 지정한 영역만** 교체하는 모드 선택 가능 (상위 해금, 정밀 플레이용) |
| 리롤 보너스 | 리롤 직후 10초간 점수 1.3배 (리롤을 "위기 탈출"에서 "공격 타이밍"으로 바꾸는 스킬) |
| 힌트 | 5초간 입력이 없으면 성립 가능한 조합 1개 반짝임 |
| 시작 부스트 | 게임 시작 시 첫 10초간 콤보 게이지 감소 없음 |

### 4.5 해금 구조

- 트리 형태: 각 계열의 하위 스킬을 찍어야 상위 스킬 개방 (선행 조건).
- 비용 곡선: 초반 스킬은 1~2판이면 해금 가능(즉각적 보상), 상위 스킬은 수십 판 목표(장기 목표). 예: 50 → 120 → 300 → 800 → 2000 코인.
- 첫 세션 안에 최소 1개 해금을 경험시키는 것이 리텐션의 핵심.

## 5. 게임 루프 & 반복 동기

```
플레이(2분) → 점수 → 코인 적립 → 스킬 해금 → 더 강해진 판 → 플레이 …
```

- **단기 동기**: 최고 점수 갱신, 콤보 쾌감.
- **중기 동기**: 다음 스킬 해금까지 N코인.
- **장기 동기**: 특수 조합 해금으로 플레이 자체가 변화 (13/17/20 빌드).
- **확장(후순위)**: 일일 도전(고정 시드 보드로 전 유저 동일 조건 경쟁), 주간 리더보드, 업적.

## 6. 화면 구성 (세로 고정)

1. **홈**: 로고, [게임 시작], [스킬트리], 최고 점수 / 보유 코인 표시.
2. **인게임**:
   - 상단 바: 남은 시간(프로그레스 바), 현재 점수, 콤보 표시
   - 중앙: 그리드 보드 (화면의 ~70%)
   - 하단: **리롤 버튼(남은 횟수 배지 표시)** + 해금된 유틸 버튼
3. **결과**: 획득 점수 → 코인 환산 연출, 최고 기록 갱신 여부, [다시하기] / [스킬트리] 버튼. **결과 화면에서 스킬트리로 바로 보내는 동선**이 반복 플레이의 핵심.
4. **스킬트리**: 4계열 분기 트리 뷰, 해금 가능 노드 강조.

### 조작 UX 디테일

- 타일 최소 터치 크기 44pt 이상 확보 (그리드 크기 결정의 제약 조건).
- 드래그 판정은 타일 중심 기준이 아니라 **사각형에 타일 중심이 포함되는지**로 판정 (관대한 판정이 스피드 게임에 맞음).
- 햅틱: 합 10 성립 순간 가벼운 진동, 제거 시 강한 진동.

## 7. 기술 스택 제안

**제안: TypeScript + Canvas(또는 Phaser) 웹 기반 → Capacitor로 iOS/Android 패키징**

| 근거 | 설명 |
|---|---|
| 빠른 반복 | 브라우저에서 즉시 플레이테스트 가능. 게임 로직(그리드, 판정, 점수)이 순수 로직이라 웹 기술로 충분 |
| 단일 코드베이스 | 웹 데모(마케팅/공유용) + iOS + Android를 하나로 |
| 그래픽 요구 낮음 | 2D 타일 + 파티클 수준이라 네이티브 엔진(Unity) 오버스펙 |
| 대안 | Flutter + Flame (네이티브 성능·햅틱 접근성 우위). 팀이 Dart에 익숙하면 이쪽도 유효 |

저장: 초기에는 로컬 저장(코인/스킬/최고점수)만. 리더보드 도입 시점에 서버(예: Supabase) 연동.

### 제안 모듈 구조

```
src/
  core/        # 순수 게임 로직 (렌더링 무관, 유닛 테스트 대상)
    board.ts       # 그리드 생성, 리롤, 조합 고갈 검사
    selection.ts   # 사각형 선택 → 타일 집합 → 합계 판정
    scoring.ts     # 점수, 콤보, 특수 숫자 효과
    skills.ts      # 스킬 정의, 효과 적용 (데이터 주도 설계)
    game.ts        # 타이머, 상태 머신 (ready → playing → result)
  ui/          # 렌더링, 입력, 연출
  meta/        # 코인, 스킬트리 상태, 로컬 저장
```

스킬은 코드 분기가 아니라 **데이터(JSON) + 효과 훅**으로 설계해, 특수 숫자·배율 추가가 콘텐츠 추가 수준이 되도록 한다.

|---|---|---|

## 9. 밸런싱 초기 가정 (플레이테스트로 검증)

- 무스킬 첫 판 기대 점수: 150~300점 (리롤 1회 포함, 보드 1.5~2판 분량 소진 가정).
- 보드 생성(초기 배치·리롤 공통): "합 10 조합이 충분히 존재"하도록 생성 후 검사·보정. 한 보드에서 이론상 지울 수 있는 총량이 판마다 크게 출렁이지 않도록 숫자 분포 튜닝 (기록 경쟁의 공정성).
- 리롤 밸런스: 리롤 1회가 대략 보드 1판 분량의 점수 가치를 갖도록. 리롤 충전 스킬(+1회)은 최상위권 비용으로 책정 — 점수 상한을 직접 늘리는 가장 강한 스킬이기 때문.
- 조합 고갈 판정: 남은 숫자로 합 10(+해금된 특수 숫자)을 만들 수 있는지 실시간 검사 → 불가능해지는 순간 리롤 버튼 강조.
- 특수 숫자 등장 빈도: 13/17은 의도해서 만들 때 판당 2~5회 수준이 되도록 숫자 분포 튜닝.
- 인플레이션 경계: 배점 스킬 총합이 +100%를 넘어가면 리더보드 도입 시 스킬 보정(정규화) 필요 — 일일 도전은 "스킬 미적용 모드"로 두는 것도 방법.

## 10. 결정 사항 & 열린 질문

### 확정된 결정

- **고정 보드(빈 공간 방식)**: 지운 자리는 빈칸으로 유지, 리필 없음. (2026-08-08)
- **리롤 시스템**: 기본 판당 1회, 스킬트리로 최대 3회까지 업그레이드. (2026-08-08)
- **올클리어 보너스 미채택**: 실제 플레이에서 올클리어 도달 빈도가 너무 낮을 것으로 판단, 제외. (2026-08-08)

### 열린 질문

1. **선택 모양**: 직사각형만 허용할지, 추후 스킬로 자유형(연결된 타일 스와이프) 해금을 열어둘지?
2. **과금/광고**: 무료 + 보상형 광고(코인 2배, 리롤 1회 충전 등)를 붙일지, 완전 무광고로 갈지 — M2 전에 결정하면 됨.
